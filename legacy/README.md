# Arquivo de versões anteriores

Este diretório conserva componentes anteriores à conexão P2P atual. **Não são necessários para jogar no SLASHER publicado.**

- `SLASHER_Demo_Offline.html`: edição antiga autônoma usada como referência histórica de interface e comportamento.
- `supabase/`: esquema e migrações SQL da arquitetura anterior, mantidos para consulta. Não precisam ser executados na edição P2P.

O ponto de entrada atual é [`../index.html`](../index.html). Para configurar o serviço de salas e TURN, veja [`../cloudflare/README.md`](../cloudflare/README.md).
